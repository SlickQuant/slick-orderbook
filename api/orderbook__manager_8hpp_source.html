73 // Non-copyable, movable (manual implementation: std::shared_mutex is neither copyable nor movable)
74 // Moving transfers the orderbooks under the source's lock; the moved-from manager is left empty.
75 // Lifetime on move:
76 // - Orderbooks of the source are transferred, not copied: pointers/handles obtained from the

78 // - Move assignment releases the destination's previous orderbooks, as clear() does: raw pointers
79 // obtained from the destination before the assignment are invalidated, unless a shared handle
80 // (getSharedOrderBook()/getOrCreateSharedOrderBook()) still retains that orderbook.
